<objective>
Wave 3 art port, character half (OFFC-07, OFFC-11, OFFC-20). Port habblaud's code-generated characters into the plugin server and expose them as one sprite-sheet renderer in the layout that plan 07-03 froze: `renderCharacterSheet` draws, for a set of poses, one 24 by 34 frame per pose, direction (down, up, left, right) and frame, at the cell `sheetCell` names, so plan 07-08 can step frames inside a clipped window and plan 07-11 can register the renderer as the `character-sheet` kind. The look of a character comes only from the agent id (`appearanceFromSeed(hash32(id))`).

Purpose: the 20-pose, 4-direction art is 3,400 lines of tuned pixel drawing, and a retyped coordinate would silently change it. The plan therefore proves the port against the unmodified upstream: a scratch-directory oracle transpiles and runs the original files once, and the tests pin hashes of its output (about 640 entries) that the ported code must reproduce frame for frame. Everything else is the usual port discipline of 07-01 (header with upstream path and commit, erasable syntax, `.ts` imports, English comments) and the size facts 07-08 and 07-11 need (how many poses fit one PNG at each zoom).

Output: `server/art/hash.ts`, `server/art/character/{parts,types,appearance,hair,render,sheet}.ts`, `server/art/icons.ts`, and `tests/ui/office-art-character.test.mjs`.

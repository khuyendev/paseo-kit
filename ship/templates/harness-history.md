# Harness history

Change history of this project's harness: the adapter (`adapter` and `gsd` sections of `.agents/harness.config.json`), project skills, project agents and project hooks. `CLAUDE.md` does not import this file; the `harness` and `harness-evolve` skills read it when they audit or evolve the harness.

One row per change, newest last. Date is ISO (YYYY-MM-DD). Scope lists repo-relative paths. Reason says why the change was made, not what it is. Supersedes names the earlier row (by date and change) this one replaces, or stays empty.

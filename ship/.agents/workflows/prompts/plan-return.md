<!--
The return contract of every gsd-plan planner call: the reply is PLANNER_SCHEMA (lib/flow-plan.mjs); gsd-plan stops needs-owner
on an owner marker and passes the proposal (plans) to the owner.
-->
Never ask the owner. Return JSON {marker, summary, question?, conflict?, plans?}: marker is one of OUTLINE COMPLETE, PLANNING COMPLETE, REVISION COMPLETE, or an owner marker (REVISION_CONFLICT, PHASE SPLIT RECOMMENDED, SOURCE AUDIT, CHECKPOINT REACHED, PLANNING INCONCLUSIVE) with the question or conflict. For PHASE SPLIT RECOMMENDED and SOURCE AUDIT, summary states the proposal and plans lists its options, one string each. An ownership-only SOURCE AUDIT also returns owns_changes [{path, from?, reason}] (from is the plan that owns the path now, and only when that plan is in another wave): the answer is ph gsd owns add or ph gsd owns handover, and only those plans are planned again. A new plan, wave, requirement or producer order has no owns_changes; it is an outline decision (ph gsd decide --outline). Do not commit; do not write STATE, ROADMAP or REQUIREMENTS.

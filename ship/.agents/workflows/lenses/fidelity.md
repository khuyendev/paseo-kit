# Lens: fidelity

Does the skeleton (outline, manifest, wiring) deliver exactly what the phase promises, nothing missing and nothing invented?

Check, citing file and row:
- Every requirement ID of the phase on the ROADMAP line is assigned to a plan row, and the row's objective actually delivers it (not just names it).
- Every locked decision `D-NN` in the phase CONTEXT is honoured by some plan; no plan contradicts one.
- Every ROADMAP success criterion of the phase is reachable from the plans' objectives; name the criterion a plan set cannot meet.
- No plan adds scope the ROADMAP, REQUIREMENTS or CONTEXT does not ask for (deferred ideas stay deferred).
- In tracer mode the tracer plan proves the riskiest end-to-end path first, with an observable outcome.

Severity: blocker when a requirement, decision or success criterion cannot be met as planned; warning when it is met only implicitly; info for wording. Target `outline` unless the gap is in the wiring contract.
